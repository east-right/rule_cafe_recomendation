# Data Collection

추천시스템의 Item이 될 카페 매장 데이터를 수집하여야 한다.

- 매장 데이터는 아래와 같은 순서로 수집하였다.
    - 카페, 베이커리 등과 같은 업종의 매장명 수집
    - 크롤링 URL parsing을 위한 place_id 수집
    - 카페 리뷰 데이터 수집

리뷰 데이터 수집 출처는 아래와 같다.

- (서울시 일반음식점 인허가 정보)[https://data.seoul.go.kr/dataList/OA-16094/S/1/datasetView.do]
- (서울시 휴게음식점 인허가 정보)[https://data.seoul.go.kr/dataList/OA-16095/S/1/datasetView.do]
- (네이버 플레이스)[place.naver.com]

## 1. 초기 매장명 데이터 수집
- 먼저 카페에 해당하는 매장명 데이터를 구할 필요가 있다.
    - (서울시 일반음식점 인허가 정보)[https://data.seoul.go.kr/dataList/OA-16094/S/1/datasetView.do]
    - (서울시 휴게음식점 인허가 정보)[https://data.seoul.go.kr/dataList/OA-16095/S/1/datasetView.do]
- 데이터을 확보하여 아래와 같이 전처리 한다.
    1. "상세영업상태명" 컬럼에서 "폐업"이 아닌 매장만 필터링 한다.(두 데이터 공통)
    2. "지번주소"에 "신림"이 들어간 지역만 필터링 한다.
        - 서울시 기준 법정동 기준 관악구 신림동 제외 "신림" 이란 단어가 들어가는 동이 존재하지 않음
    3. 일반음식점은 "기타"인 매장만 필터링 한다.
        - "기타"인 매장중 카페지만 칵테일도 같이 팔아 일반음식점으로 허가가난 매장이 존재한다.
    4. 휴개음식점은 "커피숍"인 매장만 필터링 한다. 

## 2. naver 매장 id 추출
- 네이버 맵에서 검색을 하고 리뷰를 크롤링 하는거 보단 `/pcmap.place.naver.com`에서 리뷰를 크롤링 하는것이 안정적이다.
- 그래서 **먼저 네이버 맵에서 `신림동 매장명`을 검색하여 각 매장의 place_id를 수집**
- 임반 음식점의 "기타" 데이터 때문에 "카페", "베이터리" 등과 같은 매장이 아닌 경우 해당 place_id는 수집하지 않음
- "스타벅스"와 같은 지점이 많은 경우는 추가 적인 작업이 필요
    1. 지점이 많거나 비슷한 이름의 매장 명이 많은 경우 바로 매장 정보 페이지가 뜨지 않음
    2. 그래서 맨 위에 있는 매장을 클릭해야함
    3. 클릭 후 매장 카테고리 확인

## 3. 매장 리뷰 추출
- 수집된 place_id를 기준으로 place 페이지에 접속
- 각 매장별 최대 리뷰 개수를 150로 한정
    - 모든 리뷰는 최신순으로 정렬 후 수집
    - 사진만 있고 text가 없는 리뷰 제외
    - 길이가 10이하인 리뷰는 제외 -> "좋았음", "짱", "커피가 맛있었음" 과 같이 의미 없는 리뷰가 등장할 확률이 높음
- 최종 리뷰 데이터 15233건 수집 완료
