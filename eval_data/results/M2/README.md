## 핵심 발견

- **메뉴 경로(menu_only·menu_complex)가 입력 토큰을 압도**: 요청당 ~22,000 토큰. `menu_extract`가 **전체 메뉴 목록을 매 요청 프롬프트에 통째로** 넣기 때문. 정상 경로(926 tok)의 24배.
  - 최적화 1순위: 메뉴 후보를 임베딩 검색/사전필터로 좁혀 프롬프트 투입량을 줄이면 메뉴 요청 비용을 크게 절감.
- 정상 경로는 요청당 **$0.0025 미만**으로 매우 저렴 — "정상 경로는 로컬 sLLM+규칙, LLM은 분류·답변에만"이라는 설계 주장(비교표)의 비용 근거.
- invalid_fallback은 분류 1콜(캔드 답변, OpenAI 0 답변)로 최저.

> 주의: 요청당 비용은 경로 분포에 좌우된다. 위 $0.00272는 평가 50문항 분포 기준.
