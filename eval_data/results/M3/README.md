## 핵심 발견

- **병목은 `rule_select` (3.90s)** — CPU에서 BGE-M3 임베딩 + Qwen2.5-1.5B GGUF 추론. 전체 지연의 대부분. GPU/vLLM 전환 시 최대 개선 지점(인터페이스 동일).
- **`soar_recommend`(규칙 기반 XAI 추론)은 0.007s** — 사실상 무료. 설명 가능한 단계별 추론이 지연 비용을 거의 안 유발한다는 근거(규칙 기반의 장점).
- 첫 토큰까지 **0.44s**: 답변 스트리밍이라 체감 응답은 빠름(전체 완료는 e2e).
- 문서 비교표의 "sLLM CPU 추론 1.9s"는 GGUF 선택만의 값으로 보이며, **측정된 rule_select 노드(임베딩 HTTP + 선택 HTTP 합) = 3.90s**. 임베딩까지 포함한 실측치로 갱신 필요.

> 참고: p95 표본 50개 기준. 모델서버가 상주(warm) 상태에서 측정(콜드스타트 제외).
