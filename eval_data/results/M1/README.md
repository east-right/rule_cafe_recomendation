## 핵심 (정직하게)

- **강점 — 완전 결정성**: 같은 질문을 3회 반복하면 **Rule·매장 모두 10/10 그룹 동일**. "Rule이 같으면 Trace가 결정적"이라는 설계 주장을 실측 입증. LLM 생성 추천이 매번 흔들리는 문제를 구조적으로 해결 → QA·오류 재현 용이.
- **약점 — 표현 변형 강건성 중간**: 같은 의도라도 표현이 바뀌면 Rule 66%·매장 58%만 유지. 특히 **핵심단어를 안 쓴 변형**(예: 공부→"노트북 작업", "오래 앉아 뭐 좀")에서 임베딩·sLLM 룰선택이 다른 룰로 빠짐(공부 그룹 Rule 0.2, 5종). → 요구사항 "의미 같으면 같은 추천"은 **부분 충족**.
- **룰이 같아도 매장이 갈림**(주차: Rule 1.0인데 매장 0.4): soar 동점/impasse 해소가 표현 차이로 다른 매장을 고를 수 있음.
- **LLM직접(0.78)이 변형 일치율은 더 높지만** 양면적: 혼자·인테리어·음악·콘센트는 **1곳으로 수렴**(무난한 매장 고정 경향 — 품질 보장 아님), 반대로 빵은 4곳 제각각(0.4). 게다가 LLM직접은 **재현성 보장이 없음**(규칙기반은 trace로 보장).

## 개선 방향

- 질문 **정규화·동의어 확장**(카공=공부=노트북작업)으로 임베딩/룰선택의 표현 민감도 완화.
- soar 동점 해소를 결정적 규칙으로 고정(같은 룰 → 같은 매장)해 매장 일치율 상향.
