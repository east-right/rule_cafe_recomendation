# M6 — 설명 일치도 (근거 충실도, M0 pre-B2 vs M4 post-B2)

- **커밋**: `b6b51e3` · **대상**: M0(수정 전) 답변 vs M4(B2~B4 후) 답변, 추천 문항. **OpenAI 0** (기존 실행 답변·상태 재분석).
- **근거 충실도** = 답변 프롬프트에 투입된 '근거 키워드' 중, 추천 매장의 긍정 관측에 **실제로 있는** 비율.

| 지표 | M0 (pre-B2) | M4 (post-B2) |
|---|---|---|
| 추천 문항 | 37 | 39 |
| 투입 근거 총수 | 295 | 123 |
| 실제 만족(긍정) | 111 | 123 |
| **근거 충실도** | **0.3763** | **1.0000** |

## 핵심

- **근거 충실도 37.6% → 100%**: 수정 전엔 답변에 넘긴 근거의 **62%가 추천 매장이 실제로 갖지 않은 조건**(미충족 operator)이거나 부정 조건이었다. B2 후엔 넘기는 긍정 근거가 전부 매장의 실제 긍정 관측과 일치.
- **부정 혼입 33문항 → 2문항**: 부정 조건(소음 등)을 긍정 근거로 투입하던 것이 사실상 제거. 남은 2건은 **같은 키워드가 긍정·부정 양쪽으로 관측된** 매장의 엣지(룰 정의상 tiebreak이자 negative) — 근거 자체는 긍정 관측 기반.
- 요구사항 사슬의 "설명 일치(미충족)" 항목을 **충족**으로 전환하는 직접 근거.

## 한계

- **답변 텍스트 프록시(부정어 root 등장) 32→32로 불변**: post-B2엔 부정 조건을 "최근 리뷰에서 확인되지 않음"으로 **명시 전달**하므로, 답변이 그 단어를 (올바른 프레이밍으로) 여전히 언급할 수 있다. root 문자열 존재만으로는 '강점 단정 vs 미확인 서술'을 구분 못 한다.
- 프레이밍까지 측정하려면 LLM-judge가 필요(이번엔 결정적 근거-충실도 지표로 대체, judge 미실행). 근거 충실도(0.376→1.0)가 B2 효과의 결정적 증거.
