# B2 — 답변 근거 감성·충족 분리 (회귀 vs M0)

- **커밋**: `40c8535` (`fix(B2): 답변 근거를 긍정 operator·tiebreak와 미관측 negative로 분리`)
- **기준선**: `results/M0/baseline.json` (`48c67e1`)
- **방법**: 결정적 재계산, **OpenAI 0콜**. M0 각 문항의 룰 키워드·trace·추천 매장을 그대로 재사용해 OLD 근거 vs NEW 근거를 비교.

## 무엇을 고쳤나

기존 `_extract_effective_keywords`는 답변 프롬프트의 "추천 근거"에
① **operator 키워드 전량**(추천 매장이 실제로 안 가진 미충족 포함)과
② **trace의 `neg_narrowed` 단계 = 부정 키워드**(소음 등)를 섞어 넣었다.
→ 긍정 강점으로 둔갑. B2는 추천 매장의 실제 긍정/부정 관측을 조회해:
- **긍정 근거** = 룰 operator·tiebreak 중 매장이 실제 보유한 긍정 키워드만
- **미관측 부정** = 룰 negative 중 매장 부정 리뷰에서 확인 안 된 것 → "최근 리뷰에서 확인되지 않음"으로 분리 전달(단정 금지)

## Rule / Trace / 최종 매장

**변화 없음.** B2는 `answer_generate`(+프롬프트)만 수정하므로 상류의 룰 선택·soar trace·최종 추천 매장은 M0와 동일하다. 바뀐 것은 **답변 근거 구성**뿐이다.
